# Farm-to-Table Marketplace 🌱

A front-end web project for a farm-to-table marketplace concept, created as part of a web development task. The interface includes product imagery, marketplace navigation, and a login flow.

## Highlights

- Farm-to-table marketplace interface
- Vegetable/product browsing experience
- Login page with email and password fields
- Responsive front-end structure
- Product and marketplace visual assets

## Tech Stack

- HTML5
- CSS3
- JavaScript

## Project Structure

```text
SCT_WD_1/
├── index.html          # Login page
├── vegetables.html     # Product/vegetable browsing page
├── *.css               # Page styling
├── *.js                # Client-side interactions
└── product images      # Marketplace visual assets
```

## Run Locally

```bash
git clone https://github.com/AyyapppaReddy/SCT_WD_1.git
cd SCT_WD_1
```

Open `index.html` in a modern browser, or serve the folder with a local web server.

## Purpose

This project demonstrates practical HTML/CSS/JavaScript skills through a marketplace-style user interface and basic form interaction.
